# 端到端适变跟踪技术范围说明

## 统一结论

本项目的“端到端适变跟踪”是融合跟踪模型层面的端到端，不是从原始检测点提取、
目标身份关联到航迹输出全部由一个神经网络联合学习。该口径用于后续技术报告、
软件说明、测试大纲和验收材料，避免不同材料使用不同含义。

## 软件完整流程

软件链覆盖以下步骤：

1. 接收雷达、光电、电子侦察及协同数据链原始结构化观测包。
2. 使用量测几何、匈牙利分配和时序记忆完成跨传感器、跨平台目标关联。
3. 按传感器源时间戳对齐到统一时间网格，并组织为按目标划分的注册序列。
4. 将注册后的多源时序观测输入 `CoopTrackerModel`，完成可学习状态更新、双流融合、
   Transformer时序建模和GAT协同增强。
5. 输出目标连续位置、速度和对应航迹结果。

## 模型端到端范围

- 输入：已完成时空对准和目标关联的多源时序观测，以及平台位姿和数据链时效信息。
- 输出：目标连续三维位置和三维速度状态。
- 联合学习范围：多模态编码、状态更新、时序特征提取、跨平台融合和状态回归。
- 明确不包含：原始检测点生成、目标身份初始化、目标关联规则的联合训练。

## 实现对应关系

- `scripts/pipelines/run_register_pipeline.py`：原始观测注册入口。
- `src/data_association/pipeline_core.py`：量测关联、源时间戳对齐和按目标序列组织。
- `src/data_association/track_association.py`：量测驱动的跨传感器和跨平台关联。
- `src/model.py`：注册序列到位置、速度状态的端到端融合跟踪模型。
- `tracking_system/backend/runtime.py`：模型加载、推理和航迹输出。
